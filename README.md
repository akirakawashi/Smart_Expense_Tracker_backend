# Smart-Expense-Tracker

**Fullstack-приложение для учёта личных финансов с AI-аналитикой и Telegram-ботом.**

Веб-платформа помогает вести доходы и расходы, смотреть статистику и получать подсказки по финансовым привычкам. Telegram-бот закрывает быстрые сценарии: добавить трату в пару сообщений, получить уведомление, запросить короткую сводку.

### 🤖 Интеграция с Telegram

Telegram-аккаунт привязывается к пользователю сайта через верификационный код.

Алгоритм привязки:
1. Пользователь заходит в настройки на сайте и нажимает "Подключить Telegram".
2. Бэкенд генерирует уникальный 6-значный код и сохраняет его в Redis/DB с TTL 5 минут.
3. Пользователь открывает бота в Telegram и отправляет команду /link <код>.
4. Бот проверяет код. Если всё совпало:
   * Сохраняет chat_id Telegram в профиль пользователя в БД.
   * Отправляет уведомление об успешной привязке.
5. После этого пользователь может писать боту сообщения вида Кофе 300, и они будут попадать в личный кабинет.

Команды бота:
* `/start` — Приветствие и меню.
* `/link <code>` — Привязка аккаунта.
* `/unlink` — Отвязка аккаунта.
* `/stats` — Получить краткую статистику за месяц.
* `<текст>` — быстрое добавление расхода: парсинг суммы и описания.

### 🧠 AI функционал
AI-сценарии работают через OpenAI API.

Авто-категоризация
* При создании транзакции через бота или сайт, если категория не указана явно:
* Вход: Описание "Uber поездка до аэропорта 1500 руб".
* Prompt: "Определи категорию расхода для текста: '${description}'. Варианты: Transport, Food, Entertainment, Utilities, Other. Верни только JSON."
* Выход: { "category": "Transport" }.

Финансовые инсайты
* Раз в неделю по cron или по запросу.
* Сервис анализирует транзакции за период.
* AI генерирует текст: "Вы потратили на 15% больше на рестораны, чем в прошлом месяце. Попробуйте готовить дома...".
